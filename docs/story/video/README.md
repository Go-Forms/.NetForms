# «Злой csproj» — ролик

Ролик по сценарию [`docs/story/angry-csproj.md`](../angry-csproj.md): готовое видео —
[`docs/story/angry-csproj.mp4`](../angry-csproj.mp4) (1920×1080, 30 кадров/с, H.264 + AAC, ≈3:32,
русская озвучка и субтитры). Здесь — всё, из чего оно собирается; `./build.sh` пересобирает его с нуля.

## Что в кадре настоящее

- **«Склад» — настоящее WinForms-приложение** ([`sklad/`](sklad)): `Program.cs`, `MainForm.cs` +
  `MainForm.Designer.cs`, диалог `PrihodForm`, собрано против `src/NetForms`. Его окно в ролике — рендер
  NetForms, а не картинка: [`sklad/Film.cs`](sklad/Film.cs) подменяет платформу окном без экрана и рисует
  форму через тот же `IWindowHost.Paint`, что и Avalonia-окно (масштаб 2, как на HiDPI). Клики по вкладкам,
  кнопка «Приход», поиск «бумага», количество 40 и **F2** — настоящий ввод через `IWindowHost`; строка
  статуса «Приход № 1482 … проведён» и остаток 212 → 252 — результат работы кода формы.
  `dotnet run --project sklad` открывает то же окно по-настоящему.
- **Тексты ошибок дословные** — как в сценарии; перепроверены на Ubuntu 24.04 с .NET SDK 10.0.112
  (`dotnet new winforms` → `NETSDK1100`; с `EnableWindowsTargeting` → «No frameworks were found»).
  В выводе `dotnet run` оставлены и настоящие строки «To install missing framework, download:» со ссылкой —
  по ней Лёша и кликает.
- Правка `Sklad.csproj` в сцене 4 набирается посимвольно и в итоге совпадает с дифом из сценария
  (`7 insertions(+), 2 deletions(-)`); вывод `netforms-convert` — из сценария.

## Осознанные отступления от сценария

- Актёров нет: персонажи нарисованы (SVG), голоса синтезированы RHVoice, реплики продублированы субтитрами.
- Лёша в сценах с экраном — в круглом «окне камеры», чтобы его реакции и экран были в одном кадре.
- Мониторы и ноутбуки стоят экраном к героям, а не к зрителю; что на экранах, показывают врезки крупным планом
  (ярлык «Склад.exe», «ssssss…» в терминале, «Склад» на втором мониторе — из-за плеча Гены).
- В сцене 5 Гена не катит ноутбук на тележке, а несёт его в руке (во второй — кофе) и ставит Марине Петровне на стол.
- «Торг» и «Депрессия» — крупный план доски: пишет рука Лёши с маркером, стирает — рукавом.
- Страница загрузки .NET — стилизованная, не копия настоящей; страница NetForms — в стиле `site/ru`,
  с фразами, которые Лёша читает вслух по сценарию.
- Заставка «NetForms представляет / Злой csproj» добавлена; логотип в эпилоге анимирован: форма меняет
  размер, а кнопка едет за правым нижним углом — `Anchor = Bottom | Right`.

## Как это устроено

| Файл | Что делает |
|---|---|
| [`story.py`](story.py) | Монтажный лист: реплики, паузы, набор текста, звуковые события и метки времени. Синтезирует голоса (`RHVoice-test`) и пишет `build/timeline.{json,js}`. Длительность ролика выводится из длительности реплик. |
| [`index.html`](index.html), [`engine.js`](engine.js) | Сцена 1920×1080; `renderAt(t)` детерминированно собирает кадр по времени. `index.html?t=42` — один кадр, `?play` — просмотр в браузере. |
| [`lib.js`](lib.js) | Офис и предметы — SVG. |
| [`people.js`](people.js) | Персонажи. Анфас, когда сидят и говорят: руки считаются в 3D двухзвенной инверсной кинематикой (локоть вниз и вперёд) и проецируются на экран. В профиль, когда идут: шаг привязан к пройденному пути, опорная стопа не скользит, колени сгибаются, руки качаются в противофазе. Губы двигаются по громкости реплики. |
| [`ui.js`](ui.js) | Экраны: терминал, редактор, браузер, старый рабочий стол со «Склад.exe», чат, маркерная доска. |
| [`scenes.js`](scenes.js) | Режиссура семи сцен: камера, позы, мимика, клики. |
| [`mix.py`](mix.py) | Звук: шумы (клавиши, удары, «дверь сейфа», тележка, часы, птицы, храп) и музыка синтезируются кодом, голоса обрабатываются (голос терминала — «робот», шёпот — LPC с шумовым возбуждением), музыка приглушается под речью, перед окном «Склада» — полная тишина. |
| [`render.mjs`](render.mjs) | Снимает кадры в Chromium через Playwright, 4 вкладки параллельно. `node render.mjs stills 12,60.5` — отдельные кадры. |
| [`build.sh`](build.sh) | Всё по порядку и `ffmpeg` в MP4. |

Требуется: .NET 10 SDK, Python 3 с `numpy` и `scipy`, Node 22, Chromium (Playwright), `ffmpeg` с libx264,
`rhvoice` и `rhvoice-russian`, шрифт Noto Sans (`fonts-noto-core` — им NetForms рисует «Склад» на Linux).
Шрифты ролика ставятся из npm (`@fontsource/*`), в репозиторий не кладутся; `build/` не коммитится.

## Замечено по пути

`DataGridViewColumn.AutoSizeMode = Fill` у отдельной колонки NetForms игнорирует, если у грида
`AutoSizeColumnsMode = None` (`DataGridView.ApplyAutoSizeColumns`); WinForms такую колонку растягивает.
В «Складе» поэтому `Fill` задан на уровне грида, а остальным колонкам — `None`.
