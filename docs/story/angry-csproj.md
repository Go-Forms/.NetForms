# «Злой csproj»

*Сценарий короткого ролика (2,5–3 минуты) о том, как WinForms-проект не открылся на Linux и чем
это кончилось. Для сайта, конференции, канала проекта. Все ошибки и команды на экранах — настоящие:
сняты 2026-09-24 на Ubuntu 24.04 с .NET SDK 10.0.112 (см. «Для съёмки» в конце).*

---

**Действующие лица**

- **ЛЁША** — разработчик, 30 лет. Единственный, кто помнит, как собирается «Склад».
- **МАРИНА ПЕТРОВНА** — главный бухгалтер. Работает в «Складе» с 2011 года, знает в нём каждую кнопку.
- **ГЕНА** — сисадмин. Спокоен, как человек, у которого всё уже на Linux.
- **ГОЛОС ТЕРМИНАЛА** — закадровый, бесстрастный. Читает ошибки.

---

## СЦЕНА 1. ИНТ. ОФИС — ПОНЕДЕЛЬНИК, УТРО

Опенспейс. На стене — распечатанный приказ, края загнуты скотчем.

**ТИТР:** *«С 1 числа все рабочие места переводятся на Linux».*

Гена катит тележку с ноутбуками, на крышках — наклейки с пингвином. Ставит один перед Мариной Петровной.

**ГЕНА.** Почта есть, браузер есть, таблицы есть. Всё работает.

**МАРИНА ПЕТРОВНА** *(не поднимая глаз)*. А «Склад»?

Пауза. Гена медленно поворачивается к Лёше.

**ГЕНА.** А «Склад» у нас кто?

Лёша смотрит в монитор. На мониторе — ярлык `Склад.exe`, иконка из 2011 года.

**ЛЁША.** Это WinForms. Сорок три формы. Там один `DataGridView` на весь экран, Марина Петровна им живёт.

**МАРИНА ПЕТРОВНА.** Живу.

**ЛЁША.** Ну… это же .NET. .NET теперь кроссплатформенный. Соберу.

**ГЕНА** *(уходя)*. Ну собери.

## СЦЕНА 2. ИНТ. ОФИС — РАБОЧЕЕ МЕСТО ЛЁШИ — ДЕНЬ

Новый ноутбук. Тёмный терминал на весь экран. Лёша уверенно набирает.

**ЭКРАН:**

```text
$ git clone https://git.company.local/sklad.git && cd sklad
$ dotnet build
error NETSDK1100: To build a project targeting Windows on this operating system,
set the EnableWindowsTargeting property to true.
```

**ГОЛОС ТЕРМИНАЛА** *(ровно)*. Чтобы собрать проект для Windows на этой операционной системе…

**ЛЁША** *(с облегчением)*. А, флажок. Они сами подсказывают.

**ЭКРАН:**

```text
$ dotnet build -p:EnableWindowsTargeting=true
Build succeeded.
    0 Warning(s)
    0 Error(s)
```

Лёша откидывается на стуле. Победная улыбка. Отхлёбывает кофе.

**ЭКРАН:**

```text
$ dotnet run -p:EnableWindowsTargeting=true
You must install or update .NET to run this application.

Framework: 'Microsoft.WindowsDesktop.App', version '10.0.0' (x64)
.NET location: /usr/lib/dotnet

No frameworks were found.
```

Кофе останавливается на полпути.

**ГОЛОС ТЕРМИНАЛА.** Фреймворк Microsoft точка WindowsDesktop точка App. Не найдено ни одного фреймворка.

**ЛЁША.** Ну так поставь.

Он кликает по ссылке из вывода. Открывается страница загрузки. Крупно: **«Windows Desktop Runtime» —
x64 · x86 · Arm64** и маленький значок окна Windows рядом с каждой кнопкой.

**ЛЁША** *(шёпотом)*. Для Linux нет.

## СЦЕНА 3. МОНТАЖ — «ПЯТЬ СТАДИЙ»

Быстрая нарезка под тикающие часы. В углу кадра — счётчик кружек кофе.

**ТИТР:** *Отрицание.* Лёша перезапускает `dotnet run` в третий раз. Ничего не меняется. ☕ 2

**ТИТР:** *Гнев.* Лёша читает форумы. Вкладок столько, что заголовков не видно. ☕ 3

**ТИТР:** *Торг.* Лёша рисует на доске: «Wine? Mono? Виртуалка с Windows на каждом рабочем месте?»
Гена за его спиной молча качает головой на каждый пункт. ☕ 5

**ТИТР:** *Депрессия.* На доске: «Переписать на Avalonia — 43 формы — оценка: 4 месяца».
Ниже: «Переписать на веб — 3 квартала». Лёша стирает обе строки рукавом. ☕ 7

**ТИТР:** *Принятие?* Ночь. В офисе горит одна лампа. Лёша один.

## СЦЕНА 4. ИНТ. ОФИС — НОЧЬ

Лёша открывает файл `Sklad.csproj` в редакторе. Камера — крупно на экран.

**ЭКРАН:**

```xml
<Project Sdk="Microsoft.NET.Sdk">

  <PropertyGroup>
    <OutputType>WinExe</OutputType>
    <TargetFramework>net8.0-windows</TargetFramework>
    <Nullable>enable</Nullable>
    <UseWindowsForms>true</UseWindowsForms>
    <ImplicitUsings>enable</ImplicitUsings>
  </PropertyGroup>

</Project>
```

**ЛЁША** *(медленно, сквозь зубы)*. Значит, `-windows`. Значит, `UseWindowsForms`.

Он смотрит на эти две строки, как на двух людей, которые испортили ему неделю.

В углу экрана всплывает сообщение из рабочего чата. **ГЕНА:** *«держи, вдруг пригодится»* — и ссылка:
`NetForms — Windows Forms for Windows and Linux`.

Лёша читает страницу. Камера на его лицо: брови поднимаются всё выше.

**ЛЁША** *(читает вслух)*. «Те же пространства имён. Тот же `Application.Run`. Тот же `InitializeComponent`.
Ваш код компилируется без изменений»…

Пауза.

**ЛЁША.** То есть… менять надо только это?

Он возвращается в `Sklad.csproj`. И начинает печатать — зло, с силой, как будто клавиатура в чём-то виновата.

Стирает `-windows`. **Удар по Backspace.**

Стирает строку `UseWindowsForms`. **Удар. Удар. Удар.**

Вписывает:

**ЭКРАН** *(набирается посимвольно, с каждым символом — звук удара)*:

```diff
-    <TargetFramework>net8.0-windows</TargetFramework>
+    <TargetFramework>net10.0</TargetFramework>
     <Nullable>enable</Nullable>
-    <UseWindowsForms>true</UseWindowsForms>
     <ImplicitUsings>enable</ImplicitUsings>
   </PropertyGroup>

+  <ItemGroup>
+    <PackageReference Include="NetForms" Version="0.1.0-preview.1" />
+    <Using Include="System.Drawing" />
+    <Using Include="System.Windows.Forms" />
+  </ItemGroup>
+
 </Project>
```

**Ctrl+S** — звук, как будто захлопнули сейф.

**ЛЁША.** Ну давай. Скажи мне ещё что-нибудь.

**ЭКРАН:**

```text
$ dotnet run
```

Тишина. Курсор мигает. Лёша не дышит.

На экране открывается окно. **«Склад».** Та же серая форма, тот же `DataGridView` на весь экран, те же
кнопки «Приход», «Расход», «Остатки». Шрифт чуть другой. Всё остальное — то же самое.

**ЛЁША** *(не веря)*. Сорок три формы.

Он кликает по вкладкам. Все открываются.

**ЛЁША.** Я не поменял ни одной строчки кода.

Гена смотрит на второй монитор: там открыт «Склад» на Linux.

**ГЕНА.** Хм.

**ГЕНА.** Марина Петровна, проверьте.

**МАРИНА ПЕТРОВНА.** А что изменилось?

**ГЕНА.** Ничего.

**МАРИНА ПЕТРОВНА.** Тогда хорошо.

Она возвращается к работе. Гена смотрит на спящего Лёшу. Кладёт рядом с ним свой кофе.

## СЦЕНА 6. ЭПИЛОГ — ЭКРАН

Чёрный экран. Набирается команда.

**ЭКРАН:**

```text
$ git diff --stat
 Sklad.csproj | 9 +++++++--
 1 file changed, 7 insertions(+), 2 deletions(-)
```

**ГОЛОС ТЕРМИНАЛА.** Один файл изменён.

**ТИТР:** *Шесть часов на поиски. Сорок секунд на `.csproj`.*

Ниже — ещё одна команда, спокойно, без злости:

**ЭКРАН:**

```text
$ dotnet tool install -g NetForms.Convert --prerelease
$ netforms-convert Sklad.csproj --apply
Sklad.csproj: target net8.0-windows, WinForms: yes
Changed:
  - Remove <UseWindowsForms>true</UseWindowsForms>.
  - Reference NetForms: <PackageReference Include="NetForms" Version="0.1.0-preview.1" />
  - Target framework net8.0-windows → net10.0 (so it builds and runs on Linux too).
  - Add <Using Include="System.Drawing" /> and <Using Include="System.Windows.Forms" /> (the implicit usings UseWindowsForms gave).
The sources compile against NetForms.
```

**ТИТР:** *…а можно было и не злиться.*

Логотип NetForms: окно формы с кнопкой в правом нижнем углу — `Anchor = Bottom | Right`.

**ТИТР:** **NetForms. Твой WinForms — теперь и на Linux.**
`dotnet add package NetForms`

## Короткая версия (для сайта, соцсетей, 4 кадра)

1. `dotnet build` → **NETSDK1100**. *«Чтобы собрать проект для Windows на этой ОС…»*
2. `-p:EnableWindowsTargeting=true` → **Build succeeded** → `dotnet run` → **No frameworks were found**.
3. Ночь. Разработчик со злостью стирает `-windows` и `UseWindowsForms`, вписывает `PackageReference Include="NetForms"`.
4. Окно открывается. Бухгалтер: «А что изменилось?» — «Ничего». — «Тогда хорошо».

## Для съёмки

- **Тексты ошибок — дословные.** Проверено на Ubuntu 24.04, .NET SDK 10.0.112: проект, созданный как в
  Visual Studio (`net8.0-windows`/`net10.0-windows` + `UseWindowsForms`), даёт `NETSDK1100` при сборке и
  «Framework: 'Microsoft.WindowsDesktop.App' … No frameworks were found» при запуске с
  `EnableWindowsTargeting`. После правки `.csproj` (или `netforms-convert --apply`) тот же проект собирается
  из пакета NetForms и открывает окно.
- В сцене 2 для `dotnet run` в кадре лучше оставить `net8.0-windows`: .NET 10 SDK тогда ругается на
  отсутствующий `Microsoft.NETCore.App 8.0` раньше, чем на WindowsDesktop. Для дословного текста из
  сценария проект на съёмке — `net10.0-windows`, а в кадре сцены 4 можно показать `net8.0-windows`
  (так выглядит большинство реальных проектов).
- «Склад», его формы и люди — вымышленные. Интерфейс «Склада» можно собрать из `samples/Gallery`
  (вкладки, `DataGridView`, кнопки) — это настоящий рендер NetForms.
- Звук набора в сцене 4 — главный комический элемент: каждое нажатие громче предыдущего, `Ctrl+S` — как
  дверь сейфа, `dotnet run` — полная тишина.
