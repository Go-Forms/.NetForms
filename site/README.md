# site/

The NetForms website, published to GitHub Pages at <https://go-forms.github.io/.NetForms/> by
`.github/workflows/pages.yml` on every change of `site/` or `docs/` in `main`.

- `index.html` (English), `ru/index.html` (Russian), `assets/` — the landing pages, as they are.
- The documentation is not written here: `build.mjs` renders `docs/*.md` (English), `docs/ru/*.md` (Russian)
  and `docs/api/*.md` (generated by `tools/NetForms.ApiDiff --markdown`) into the site's layout, with a
  contents menu, heading anchors and links rewritten from `.md` to pages. The list of pages and their menu
  titles is at the top of `build.mjs`; a new page is a new Markdown file plus a line there.

```sh
cd site
npm ci
npm run build      # -> ../_site
npm run serve      # http://localhost:8080
```

The pictures in `assets/` are copies of `docs/images/` and `eng/branding/`. The numbers in the "Status" section
of both landing pages come from `docs/compatibility.md` — update them together on each release.
